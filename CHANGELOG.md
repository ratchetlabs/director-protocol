# Changelog

All notable changes to this protocol are documented here.

## 0.3.0 — the front end + the four-functions framing

- **README "What it actually does"**: the mechanism layer named — memory outside the
  model, claims with pointers, arc-level continuity of intent, shared-and-verifiable
  multi-agent context; scrutiny-survival reframed as the corollary.
- **NEW `DESIGN.md`** — the adversarial discovery/design front end the registered cycle
  depends on: unconstrained-best-first, named-voices red-team passes, question-first
  arcs, layer-mapped design docs, design freeze + one arbiter round, the 5-line kickoff
  block. Extracted from the source project's charter + process rules; the registered
  cycle certifies answers — this is what makes the questions worth answering.
- **NEW `RESEARCH.md`** — the exploratory-search protocol (the source project's §H):
  answer-not-novelty prime directive, tiered coarse budgets w/ split search pool,
  fetch/harvest/direct model routing, the generate-walk-checkpoint-prune-recombine
  round loop, protected explore tranche, analogy sweeps, one adversarial look at the
  synthesis, the one-knob retro, cross-run stepping-stones retention.
- Repo map + quick start wired to both.

## 0.2.0 — the scaling period: orchestration, arcs, the tier economy

- **ORCHESTRATION.md** (new): the multi-seat structure that ran in production — seats
  (fences bound writes, not thought), files-as-state with kill-safe commits, the
  committed-fact inbox protocol, four governance roles (registrar, non-party
  gatekeeper, auditor, producer), arc-level signatures with a mechanical conformance
  gate, and the model-tier economy (strip ritual, keep the floor, route judgment).
- **PROTOCOL.md §G+** (new): the amendments the scaling period added to the lean
  cycle — proportionality + collaborative pushback, the arbiter economy (in-house
  ladder, three-leg dispatch test, structural-vs-editorial, ONE round per slot),
  goal-gain, bytes-before-statements + counts-name-their-derivation, graded stamps +
  reviews-name-what-they-re-derived, orphan-step census, critical-path register,
  unconditional risk sections, rule-supersession (the rulebook must trend down).
  Cycle steps 3 (one arbiter round) and 4 (routine gates self-clear) amended in place.
- **tools/** (new): `gate_check.py` — the non-party conformance gate as a runnable,
  dependency-free script (re-hash · data audit · boundary set-membership · standing-law
  form checks; NEEDS-JUDGMENT routes, the tool never judges) with a planted-case
  selftest and a starter data ledger.
- **case-studies/05-tier-transition.md** (new): moving three seats to a mid-tier model
  under the profile — day-one self-caught errors, a cheap-model seat correcting a
  strong-model seat's committed claim, supervision converging to sampling.
- **CHECKLISTS.md**: +§11 conformance gate (gatekeeper), +§12 arc registration;
  arbiter checklists note the one-round law; user-gate checklist gains the
  self-clearance form.
- **templates/**: +ARC-SCOPE, +SEAT-CHARTER, +INBOX-NOTE, +GATE-MANIFEST; HANDOFF
  gains the core-plus-layers multi-seat form.
- **DIRECTOR.md**: retitled (the PI vocabulary is retired for "director"); new
  sections — finding your own errors is a success; the generative close-question.
- **claude/**: `director.md` init gains inbox drain (delete-is-ack), own-residue
  reconciliation (expect the killed predecessor), literal-tail reads, and monitors;
  charter block gains the new trigger rows.
- **ADAPTING.md**: the stepwise path into orchestration (each governance seat at its
  pain point; tier economy last, after the floor is field-validated); freeze-manifest
  format + re-hash gate recipe; inbox-monitor wiring per harness class; solo/humanless
  ladder assignments.
- **Cold-reader verification pass (the release gate, re-run for 0.2)**: 17 findings
  fixed — close-packet contents specified; claim-script expectation stated; §G
  numbering legend; slot definition for the one-round law; per-registration (not
  per-arc) arbiter accounting at the gate; registrar named canonically; digest
  required fields + scope-card definition; A2-vs-A4 boundary for deterministic
  claims; B1 list alignment; §G.24/§G.25 split; jargon glosses — plus one real
  `gate_check.py` bug (the two legs could audit different ledgers under
  `GATE_CHECK_REPO`; both now derive from the same root, selftest case pins it).
